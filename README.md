# FerchGam PDF

© FerchGam. Todos los derechos reservados. Creado por FerchGam.

App para convertir PDF a PNG, Word y PowerPoint, y firmar documentos con firmas guardadas.

## Cómo se obtiene el APK
Cada vez que se sube un cambio a `main`, GitHub Actions compila la app y publica el APK en **Releases**.

- Interfaz: `app/src/main/assets/index.html`
- Código Android: `app/src/main/java/com/ferchgam/pdf/MainActivity.java`
- `keystore/test.keystore` es solo para versiones de prueba. Para Play Store se usará una llave privada guardada como secreto de GitHub.
